# 三维写评审

每份 Draft 由 LLM judge 沿三个维度评审：事实准确性（每条论断都有来源支撑）、结构清晰度（章节跟随 Outline）、引用完整性（所有引用过的来源都出现在 References 中）。三维全通过后才进入 Polish；不通过则触发草稿修订。

## 备选方案

- **三维（已选）**：定位具体的失败模式（事实错 / 跑题 / 漏引用），让重写 prompt 知道该改什么。
- **单维度整体评分（0–10）**：更简单，但低分不告诉我们要改什么。
- **仅一个维度（仅事实准确性）**：最便宜，但会放过结构不符与未引用的草稿。

## 影响

- Review 节点为每个未通过的维度产出一份结构化 `ReviewNote`，由 Drafter 作为修订指引消费。
- Polish（ADR 邻近）的职责被限制在衔接、术语、错字——不改变事实、结构或引用，使 Review 维度在 Polish 之后仍然成立。
- 增删维度需要同步修改 Review prompt 与 Drafter 的修订逻辑。
